# Histórico de versões

## v0.1.0 — Primeiro Pensamento (22/10/2026)

- Criação de reflexões com biblioteca, estados, etiquetas, arquivamento e duplicação.
- Editor gráfico com 12 tipos de blocos, reposicionamento, zoom, minimapa, conexões e modo histórico.
- Debate entre perspectivas internas personalizáveis, provocações e ações rápidas.
- Retorno à questão central, recolhimento de ramificações e reorganização automática.
- Desfazer/refazer de mapa durante a sessão, salvamento automático local e modo claro/escuro.
- Exportação do mapa inteiro como SVG/PNG, Markdown estruturado, backup JSON e prompt de análise para IA.
- PWA offline, deploy estático GitHub Pages, amostra importável e testes unitários para formatos/modelo.

Limites: sem sincronização em múltiplos dispositivos, histórico de undo não persistido, sem análise automática de contradição, PNG sujeito a limites do navegador.
